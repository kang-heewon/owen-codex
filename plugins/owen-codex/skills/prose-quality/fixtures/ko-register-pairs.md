# 한국어 도메인 레지스터 짝 사례

각 단어에는 문맥상 고쳐야 하는 사례와 그대로 보존해야 하는 사례가 모두 있다. 단어 자체를 오류로 분류하지 않는다.

## 배선

### Rewrite candidate — 소프트웨어 구성
Bad: “서비스와 저장소를 배선한다.”

Better: “서비스와 저장소를 연결한다.”

Reason: 일반적인 소프트웨어 설명에서는 `연결한다`가 더 자연스럽다.

### Preserve — 전기 설비
Good: “제어반의 전원 배선은 접지선과 분리한다.”

Reason: 전기·하드웨어 문서에서 `배선`은 정확한 전문 용어다.

## 계측

### Rewrite candidate — 소프트웨어 관측성
Bad: “API에 계측을 추가해 응답 시간을 본다.”

Better: “API에 메트릭과 트레이싱을 추가해 응답 시간을 확인한다.”

Reason: 관측 데이터의 종류를 구체적으로 말하는 편이 소프트웨어 문맥에 맞다.

### Preserve — 하드웨어 시험
Good: “전압 계측 장비는 교정 주기를 12개월로 유지한다.”

Reason: 계측기·센서 문서에서는 올바른 용어다.

## 노출

### Rewrite candidate — 사용자 기능
Bad: “설정 화면에서 저장 기능을 노출한다.”

Better: “설정 화면에서 저장 기능을 제공한다.”

Reason: 사용자 기능 제공을 설명하는 문맥에서는 `제공한다`가 자연스럽다.

### Preserve — 보안 경계
Good: “관리 엔드포인트를 공용 인터넷에 노출하지 않는다.”

Reason: 공격 표면과 endpoint exposure를 뜻하므로 `노출`이 정확하다.

## 소비

### Rewrite candidate — 일반 이벤트 처리
Bad: “화면이 클릭 이벤트를 소비하고 알림을 띄운다.”

Better: “화면이 클릭 이벤트를 처리하고 알림을 띄운다.”

Reason: 일반 애플리케이션 동작에는 `처리한다`가 익숙하다.

### Preserve — 스트리밍 아키텍처
Good: “각 consumer group은 토픽을 독립적으로 소비한다.”

Reason: Kafka consumer 동작을 설명하는 정착된 전문 문맥이다.

## 주입

### Rewrite candidate — 단순 인자 전달
Bad: “함수에 현재 시간을 주입한다.”

Better: “함수에 현재 시간을 인자로 전달한다.”

Reason: 단순한 인자 전달이라면 구체적인 동작을 쓰는 편이 명확하다.

### Preserve — 의존성 주입
Good: “테스트에서는 저장소 구현을 생성자 주입으로 교체한다.”

Reason: Dependency Injection의 `주입`은 정착된 설계 용어다.

## 전파

### Rewrite candidate — 화면 반영
Bad: “이름 변경을 프로필 화면에 전파한다.”

Better: “이름 변경을 프로필 화면에 반영한다.”

Reason: 단일 화면 업데이트에는 `반영한다`가 더 직접적이다.

### Preserve — 분산 시스템
Good: “설정 변경이 모든 리전에 전파되기까지 최대 30초가 걸린다.”

Reason: 여러 노드로 퍼지는 propagation의 의미를 정확히 나타낸다.

## 활용

### Rewrite candidate — 단순 사용
Bad: “이 함수는 배열을 활용해 결과를 반환한다.”

Better: “이 함수는 배열을 사용해 결과를 반환한다.”

Reason: 특별한 운용상의 의미가 없으므로 `사용한다`가 직접적이다.

### Preserve — 자원 효율
Good: “유휴 GPU를 효율적으로 활용하기 위해 작업을 묶어 실행한다.”

Reason: 가용 자원을 목적에 맞게 활용한다는 뜻이므로 이 문맥에서는 정확하다.

## 취하다

### Rewrite candidate — 값 읽기
Bad: “설정 파일에서 포트 값을 취한다.”

Better: “설정 파일에서 포트 값을 가져온다.”

Reason: 일반 개발 안내에서는 `가져온다`가 자연스럽다.

### Preserve — 수학적 정의
Good: “함수는 닫힌 구간에서 최댓값을 취한다.”

Reason: 수학 문맥의 정착된 표현이므로 보존한다.
